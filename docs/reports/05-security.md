## Round 4 (13 Nov): USDC pool (`lend/`, `pusaka-lend.testnet`; started on pUSD, moved to Circle USDC on 13 Nov)
| Threat | Defense | Test |
|---|---|---|
| One reporter lies to liquidate everyone | median of 3 reports; quorum of 2 | `a_lying_reporter_is_outvoted_by_the_median` |
| With 2 reports, one source shifts the price (automated review finding) | borrowing uses the lower middle value, liquidation the upper middle value; a difference > 5% means there is no price | `with_two_reports_one_source_cannot_move_the_price_either_way` |

## Known issues (not fixed, with reasons)
1. **A full CSP `script-src` is not set.** `@hot-labs/near-connect` runs wallet code in a `srcdoc` iframe, which inherits the parent page's CSP, so a strict CSP kills every wallet. What is set: `frame-ancestors 'none'` + XFO DENY. The XSS surface is small: React without `dangerouslySetInnerHTML` from user input (the QR SVG is built from a contract-derived address).
2. **Holder room nonce is single-use per instance (R5-3).** A replay that lands on another serverless instance within ≤ 5 minutes can still get through. Next fix: a shared store (Upstash Redis `SET NX` TTL 5 minutes).
3. **Appraisal cost limit is per instance (R5-6).** A Vercel Firewall rule can be added for `/api/appraise`, as for `/api/prove` and `/api/relay`.
4. **NEAR AI image provenance (R5-10)** is not verified through Sigstore; the digest and the unpinned images are shown.
5. **`elliptic` low (R5-8)**: does not apply to verification; there is no replacement without a more severe advisory.
6. **Clippy style warnings**: left as is so the contract source stays identical to the deployed build.
