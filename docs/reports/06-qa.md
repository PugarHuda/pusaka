### Yang tidak diotomatisasi (jujur)
- **Wallet menolak / saldo kurang / ganti akun di tengah alur**: wallet NEAR adalah halaman pihak ketiga; tidak ada provider injeksi seperti Anvil+viem untuk EVM. Jalur penolakan ditangani di kode (`callGasless` tidak mengulang penolakan) dan diuji manual lewat `wallet-qa.mjs` dengan wallet Intear sungguhan.
- **Node lokal/fork**: tidak ada padanan Anvil untuk NEAR+MPC+light client; tes berjalan terhadap testnet publik (bukan simulasi).
- **Page Object Model**: tidak dipakai; spesifikasi pendek dan memakai locator berbasis role/teks. Menambah lapisan POM untuk 50 tes tidak mengurangi duplikasi yang berarti.
